# @amlplugins/atlassian-confluence

Native `confluence.js` SDK re-exported under the `@amlplugins` namespace.

> Confluence Cloud REST API v2 — spaces, pages, blog posts, comments, attachments, properties.

## Install

```bash
npm install @amlplugins/atlassian-confluence
```

## Use

```ts
import { /* named exports from confluence.js */ } from "@amlplugins/atlassian-confluence";
// or
import sdk from "@amlplugins/atlassian-confluence";
```

This package additionally re-exports `atlassian-jwt` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
